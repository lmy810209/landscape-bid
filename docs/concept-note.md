## 2. 이론적 하한 + 실측 검증 (핵심)

### 2.1 메커니즘

한국 공공 조경 입찰 복수예비가격:
1. 발주처가 기초금액 $B$ 기준 **15개 예비가격** $p_1, ..., p_{15}$ 사전 산정 (통상 ±2~3% 범위, 균등분포 관행).
2. 개찰 시 15개 중 **4개를 무작위 추첨** → 4개 산술 평균 = 예정가격 $E$.
3. $E$에 **낙찰하한율 $L$** 곱해 낙찰하한금액 산출 (통상 $L \approx 0.88$).
4. 적격 구간 안 최저 투찰자 낙찰.

핵심: **$E$는 랜덤 변수**. 같은 공고에서도 추첨이 다시 돌면 예정가격이 달라짐.

### 2.2 $E$의 이론적 분산 (균등분포 가정)

> v1에서 "대략 정규"라 썼던 가정을 **균등분포로 정정**. 실측 왜도(skew=0.12)와 첨도(kurt=−1.15, 평평)가 균등분포에 가까운 패턴을 지지.

예비가격 분포 범위 $\pm R$의 균등분포라면:
$$\sigma_p = \frac{R}{\sqrt{3}}, \quad R \in \{0.025, 0.03\}$$

15개 중 4개 비복원 추출의 표본평균 분산:
$$\text{Var}(E) = \frac{\sigma_p^2}{4} \cdot \frac{15-4}{15-1} = \frac{11}{56}\sigma_p^2 \approx 0.196\, \sigma_p^2$$

| 예비가격 범위 | $\sigma_p$ | $\text{SD}(E)$ |
|---|---|---|
| ±2.5% (균등) | 0.0144 | **0.66%** |
| ±3% (균등) | 0.0173 | **0.77%** |

### 2.3 낙찰하한금액까지 전파 (DeepSeek 지적)

낙찰하한금액 $= L \cdot E$ 이므로:
$$\text{Var}(L \cdot E) = L^2 \cdot \text{Var}(E)$$

$L \approx 0.88$이면 분산이 $0.88^2 = 0.774$배로 **줄어듦**:

| 가정 | SD(낙찰하한금액 / 기초) |
|---|---|
| ±2.5% | $0.88 \times 0.66\% \approx 0.58\%$ |
| ±3% | $0.88 \times 0.77\% \approx 0.68\%$ |

### 2.4 **실측 결과** (18건, 2026-04-24 계산)

스크립트: [`scripts/measure.mjs`](../scripts/measure.mjs)

**기술 통계**:
- $n = 18$
- mean = **89.345%**
- median = 89.164%
- **$s = 1.135\%$** (95% Bootstrap CI: [0.810%, 1.388%])
- min = 87.36%, max = 91.48%, range = 4.12%
- **skew = 0.12** (거의 대칭)
- kurt = −1.15 (평평)

**이론 vs 실측**:

| 가정 | 이론 SD | 실측 SD | 실측/이론 비 |
|---|---|---|---|
| 균등 ±2.5% | 0.66% | 1.135% | **1.72×** |
| 균등 ±3% | 0.77% | 1.135% | 1.47× |

**발주처 노이즈 분해** (Gemini §1 제안):
$$\sigma_{total}^2 = \sigma_{draw}^2 + \sigma_{bias}^2 \Rightarrow \sigma_{bias} = \sqrt{s^2 - \text{SD}(E)^2}$$

| 가정 | $\sigma_{draw}$ | $\sigma_{bias}$ |
|---|---|---|
| ±2.5% | 0.66% | **0.923%** |
| ±3% | 0.77% | 0.834% |

**즉 실측 분산의 66%가 발주처 편향에서 옴** ($\sigma_{bias}^2 / s^2 = 0.923^2 / 1.135^2 \approx 0.66$). 추첨 분산만으론 설명되지 않음.

**Quantile**:
- Q10 = 88.10%, Q25 = 88.48%, Q40 = 88.94%, Q50 = 89.16%, Q75 = 90.34%, Q90 = 90.62%
- **IQR (실측 50% 구간 폭) = 1.864%**

**구조 확인**:
- 현재 `BIN_SIZE = 0.3%`는 실측 IQR의 **16%** (1/6 수준)
- 즉 "50% 구간에 들어갈 확률"을 기대한다면 구간 폭을 **최소 6배 확장** 필요

### 2.5 결과 상태별 분포 (Gemini §5 질문 답)

| 상태 | n | mean | 개별값 |
|---|---|---|---|
| 순위권밖 | 10 | 88.64% | 87.36~90.43% |
| **낙찰하한선미달 (부적격)** | **7** | **90.19%** | 88.96, 89.58, 89.77, 90.32, 90.35, 90.85, 91.48 |
| 낙찰 | 1 | 90.52% | — |

**부적격 그룹의 위치**:
- z-score = **+0.74** (전체 평균보다 위)
- 부적격은 **경쟁이 약한(사정율이 높은) 공고에 집중**
- 해석: 1등 사정율이 높은 공고는 낙찰하한선도 높음 → 내 투찰이 이 벽을 못 넘김

→ 이 +0.74가 **부적격 회피 보정의 첫 파라미터** (§4.5)

### 2.6 함의

1. **실측 SD = 1.135%**. 현재 구간 폭 0.3%는 이 값의 **1/4**, IQR의 **1/6**. 구조적으로 너무 좁음.
2. **발주처 편향 ($\sigma_{bias}$)이 추첨 분산보다 큼**. 발주처별 세분화가 언젠가는 필요 (단 표본 부족으로 지금은 불가).
3. **Skew가 약함 → 대칭 Quantile로 충분**. 비대칭 구간 도입은 불필요 (Gemini 예측 일부 반증).
4. **데이터 1,700건이 되어도 $\sigma_{draw} \approx 0.66\%$는 안 줄어듦**. 전체 도구 오차 하한은 여기.
5. **단, 조건부 하한은 다름**: 발주처 $A$를 고정하면 $\sigma_{bias}|A$가 크게 줄 수 있음. 즉 "전체 오차 하한 = $\sqrt{\sigma_{draw}^2 + \sigma_{bias}^2}$"인 반면 "발주처 $A$ 조건부 하한 = $\sqrt{\sigma_{draw}^2 + \sigma_{bias|A}^2}$". 후자가 P4 이후 발주처별 세분화의 동기.

## 3. 목표 지표 재정의

### 3.1 현행 "포함률"의 함정

- 구간 폭을 넓히면 공짜로 올라감 → 품질 지표 아님
- "포함률 60%"와 "17%" 중 어느 것이 좋은지 **구간 폭을 모르면 판단 불가**

### 3.2 대안: Calibration + Sharpness + Bootstrap

**Calibration**: "$\alpha$% 신뢰구간이라고 선언했을 때 실제로 $\alpha$%가 들어오는가?"
- 목표 커버리지 $\alpha \in \{0.5, 0.8\}$를 **명시적으로 선언**
- 실측 포함률이 $\alpha$에 가까울수록 잘 캘리브레이션됨

**Sharpness**: 구간 평균 폭. 좁을수록 좋음 (단 이론 하한 ≥)

**Bootstrap 95% CI** (Gemini §4 제안): 모든 지표에 **신뢰구간 병기 의무**.
17건에서 점 추정만 보면 우연에 취약. 1000회 리샘플링으로 변동성 명시.

### 3.3 새 백테스트 지표

| 지표 | 계산 | 이론 기준 |
|---|---|---|
| **Calibration@50** | 50% 구간 (Q25~Q75) 실측 포함률 | 50%에 ±5%p 근접 |
| **Calibration@80** | 80% 구간 (Q10~Q90) 실측 포함률 | 80%에 ±5%p 근접 |
| **Sharpness@50** | 50% 구간 평균 폭 | 이론 하한 ≈ $1.349 \times 0.58\% \approx 0.78\%$ |
| **Sharpness@80** | 80% 구간 평균 폭 | 이론 하한 ≈ $2.563 \times 0.58\% \approx 1.49\%$ |
| **vs User MAE ratio** | 도구 MAE / 사용자 MAE | **< 1** 이어야 의미 |
| **Improvement rate + 95% CI** | Wilson 또는 Bootstrap | CI가 50%를 포함하면 "유의하지 않음" |

"포함률"은 Calibration@50의 별칭으로만 유지.

### 3.4 Skew 모니터링 (조건부)

현재 skew=0.12로 대칭 Quantile 유지. 단 데이터 축적 후 **|skew| > 0.5** 가 되면 비대칭 Quantile (40~90 등) 재검토.

## 4. 개인 보정 재설계 (자기참조 제거)

### 4.1 현행 문제

```
my_gap_rate = (winning − my_bid) / base
```

사용자가 도구를 따르면 `my_bid`가 도구 출력 → 보정이 자기에게 수렴.

### 4.2 대안 A: 시장 중앙값 대비 편향 — **불충분 (Claude 지적)**

```
my_tilt = my_bid_ratio − market_median
```

표면적으로는 `market_median`이 과거 낙찰 분포라 안전해 보인다. 그러나:
- 사용자가 도구 따르면 `my_bid_ratio = market_median + recommended_tilt`
- 다음 기간 `my_tilt = recommended_tilt`
- 보정값이 **도구 자신의 과거 추천 평균**으로 수렴

→ **A도 자기참조에서 못 벗어남. 한 층 멀어진 것뿐.** 나중에 A로 회귀하려는 유혹을 이 문단이 차단한다.

### 4.3 대안 B: Collision Warning (Gemini 제안, 채택)

개인 보정의 **목적을 좁힌다**: "내 습관 보정"이 아니라 "**하한선 충돌 경고**".

```
dangerous_distance = my_bid_ratio − lower_bound_ratio
```

- `lower_bound_ratio`: 해당 공고의 추첨 기반 낙찰하한선 사정율
- 과거 부적격 건들의 `dangerous_distance` 분포를 학습
- 다음 투찰 시 **내 투찰값이 부적격 그룹 z-구간에 들어가면 경고**
  - 파라미터 (실측 기반): 부적격 그룹 z = +0.74 근방

**핵심 차이**: 투찰가를 **바꾸지 않는다**. 경고만 한다. 사용자가 판단.
→ "도구는 기사가 아니라 레이싱 엔지니어의 무전" (Gemini §6 비유)

### 4.4 대안 C: 보정 자체 제거

현재 데이터 18건 × 부적격 7건 기준, 표준편차 추정 신뢰구간이 ±100% 수준 → B도 지금은 불안정.

### 4.5 권장 (단계별)

| 시점 | 보정 |
|---|---|
| **현재 (n < 30)** | **C 채택 — 개인 보정 모듈 제거** |
| 30건+ 누적 시 | **B 도입 (Collision Warning)** — z=+0.74 파라미터는 재측정 |
| 100건+ 누적 시 | 발주처별 B 세분화 고려 |
| **절대 안 감** | A (자기참조 못 벗어남) |

**즉 지금 할 일: 모듈 구조는 유지, 기능만 비활성**.
- `personalAdjustment.ts` 코드는 그대로 둠 (30건+ 시 재활성 대비)
- `ADJUSTMENT_FACTOR` 또는 호출 경로에서 `adjustment = 0` 강제 (설정 플래그)
- `finalBid`는 `adjustment` 입력을 여전히 받되, v2.1 시점에는 항상 0
- UI에서 "개인 보정 카드"를 숨김 처리 (삭제 아님)

이렇게 두면 30건 누적 후 B(Collision Warning) 도입 시 플래그 하나만 뒤집어 재활성.

## 5. GoNoGo 재구성

### 5.1 현행 문제 (Claude §3 지적)

- "공고 속성만 100점"을 선언했는데 개인 적합도 15점 포함 → **내부 모순**
- 자격 요건이 15점짜리 소프트 항목 → 실무에서는 **이진 게이트**여야 함
- "데이터 신뢰도 30점"은 공고 속성이 아니라 **도구 내부 상태** → 혼동
- **"경쟁 강도 30점"은 투찰 시점에 참가업체 수를 모른다** → 추정치의 추정치 위에 30점 얹는 건 재고 필요

### 5.2 재구성안

**1차: 이진 게이트** (실패 시 점수 계산 없이 즉시 NO-GO)
- 자격 요건 충족 (실적·면허·시평액·지역제한)
- 금액 범위 (내 회사 캐파 대비 과소·과대 아님)

**2차: 공고 점수 85점** (공고 속성만)

| 항목 | 점수 | 계산 | 비고 |
|---|---|---|---|
| 예상 경쟁 강도 | **15** | 과거 동일 조건 참가업체 평균 | 투찰 시점 미지 → "추정치" 배지 |
| 예상 마진 | 25 | 기초금액 규모, $\sigma_{bias}$ 큰 발주처면 감점 | |

**3차: 개인 적합도 ±15점** (별도, 데이터 있을 때만)
- 참여 이력 있음: +5~+15
- 참여 이력 없음: **0점이 아닌 N/A** (총점 스케일 85점으로 표시)

### 5.3 임계 재설정

- 공고 점수 85점 만점 기준:

  - **50 ~ 69** → 참고 검토

### 8.2 판단 기준

- **(사용자 직관 단독) vs (도구 본 후 사용자)** Wilcoxon signed-rank test
- p < 0.05로 도구 본 후가 유의하게 낫다 → 현재 방향 유지
- 그렇지 않다 → 도구 축소: §8.1의 1번(기록/복기)으로 전환

## 10. 측정 프로토콜 (신설, Claude §4 제안)

### 10.1 왜 필요한가

현행 백테스트의 "개선률" 지표는 "**도구 단독 vs 사용자 단독**"을 비교한다. 이건 **잘못된 비교**다. 실사용에서 사용자는 도구를 보고 자기 직관과 합친 뒤 투찰한다. 따라서 측정해야 할 것은:

> "**도구를 본 뒤 사용자**" vs "**도구를 안 본 사용자**"

### 10.2 A/B 쌍체 기록 구조

공고 등록 시 아래 순서로 값을 기록:

| 단계 | 필드 | 기록 시점 |
|---|---|---|
| 1 | `guess_ratio` | 공고 입력 완료 직후, **분석 화면 들어가기 전** |
| 2 | `my_bid_ratio` | 분석 본 후 최종 투찰 사정율 |
| 3 | `winning_ratio` | 개찰 결과 |

UI 원칙: `guess_ratio`는 **선택 입력**. 강제 게이트는 사용자 짜증을 유발함. 대신 다음과 같이:
- 공고 등록 폼에 "분석 전 예상 사정율 (선택)" 필드 추가
- 입력 시 UI 안내: "**과거 데이터를 보기 전에 직관으로 찍어주세요**"
- 미입력 건은 측정 프로토콜 분석에서 **제외**. 자발적으로 N≥30 도달이 현실적.
- 이렇게 하면 쌍체 측정 자체는 편향될 수 있으나(응답자 편향), 강제로 얻은 데이터가 오히려 더 오염될 위험 회피.

### 10.3 지표

$$\text{guess\_error} = |\text{guess} - \text{winning}|$$
$$\text{bid\_error} = |\text{my\_bid} - \text{winning}|$$
$$\text{delta} = \text{guess\_error} - \text{bid\_error}$$

**delta > 0** 이면 도구가 도움이 됨. **delta < 0** 이면 오히려 방해.

### 10.4 통계 검정

- $N \geq 20$ 쌍체 표본 도달 시 **중간 점검** (방향성 확인, Wilcoxon)
- $N \geq 30$ 쌍체 표본 도달 시 **최종 판정** (유의성 결정, Wilcoxon)
- Wilcoxon signed-rank는 $n \geq 12$부터 안정적이나, 도메인 특성상 $n=30$이 최소 권장선
- 정규성 가정 없음 → 작은 표본·스큐 분포에 안전
- Paired t-test는 정규성 가정 필요 → 조심스럽게 보조 지표로만

### 10.5 해석 룰

| p-value | delta 중앙값 | 판정 |
|---|---|---|
| < 0.05 | 양수 | **도구 유효** — 현재 방향 유지 |
| < 0.05 | 음수 | **도구 유해** — §8.1 1번으로 축소 (기록 도구화) |
| ≥ 0.05 | — | **결론 보류** — 표본 추가 |
